## 0. 本轮设计要解决的问题

旧原型只覆盖主工作台一个静态画面，无法支撑正式实现：

- 添加数据、WMTS、Cesium ion、DEM、配准、拾取、诊断、脚本工作台等入口没有完整设计；
- 图层状态只有“就绪/加载中”，缺少暂停、部分失败、失败、取消等真实流送状态；
- 移动端只画了主界面，抽屉、底部面板、键盘、横屏规则缺失；
- 视觉令牌与 `themes/digitalviewer_theme.tres` 未对齐，实现时需二次猜测；
- 未定义 1366×768、1100 px 断点、面板折叠与全屏视口的精确行为。

v1 设计给出可实现的布局、组件、状态与交互规则，并保持与现有工程骨架兼容。

> **2026-10-23 重新基线**：v1.0 纳入多视口。桌面/Web 使用多视口，桌面支持独立窗口，Web 只能停靠；移动端单视口。每个视口拥有独立 World3D、相机、图层栈与设置；添加数据创建独立数据，只有拖放图层到另一视口才建立共享数据引用。v1 不内置 AI；原生脚本是应用级面板，不绑定单个视口；移动端不提供脚本与 AI。

## 1. 设计目标与原则

**目标**：做一个“测绘仪器级”的专业三维数据浏览工作台——信息密度高、状态透明、操作可预期，而不是消费级地球演示。

1. **视口优先**：任何常驻面板都不得把活动视口压到不可操作；不设视口最小尺寸，极小视口用紧凑标题栏与浮层收拢；全屏活动视口是一等能力（`Ctrl+Shift+F`）。
2. **状态透明**：每个图层始终可见“当前阶段 + 进度 + 内存 + 失败原因”；错误必须可复制、可重试、可定位到图层与视口。
3. **会话即真相**：v1 不保存工作空间、最近文件、URL、Token、图层、配准或视点。UI 不出现“最近打开”“历史记录”等暗示持久化的入口。
4. **桌面密度 / 移动触控**：桌面单位 13 px、行高 38–40 px；移动主要触控目标 ≥ 44 px，信息层级降为“视口 + 抽屉 + 底部面板”。
5. **双语同步设计**：中英文文案同时设计，拒绝“先中文再翻译”；所有容器按英文长文案预留宽度。
6. **v1 无内置 AI**：右侧只放属性，脚本默认在底部；桌面可独立成窗口，Web 只能停靠；外部 AI 仅通过本机 MCP 操作运行时场景。
7. **视口是独立工作单元**：每个视口拥有独立 World3D、相机、图层栈、选中项和显示设置；每视口图层树、右侧属性、添加数据和显示设置跟随活动视口；脚本是应用级。
8. **共享数据、独立呈现**：添加数据创建独立数据；只有把图层拖到另一视口才建立共享引用。共享的是底层数据与 GPU 资源，显隐、透明度、顺序、渲染模式仍按视口独立；最后一个引用移除时才释放数据。
9. **平台边界**：多视口版本用于桌面 + Web，Web 面板与视口不可独立；单视口版本只用于移动端，移动端没有脚本面板。

## 2. 页面地图

```
DigitalViewer
├─ 桌面 / Web Shell（≥1100 px）
│  ├─ 顶部工具栏（品牌应用菜单、属性、脚本、FPS、设置）
│  ├─ 工作区
│  │  ├─ 视口区域（1–N 个递归分屏视口，每视口独立 World3D/相机/图层/设置）
│  │  │    每个视口含三区标题栏：左（树 + 添加 + 飞往/视点/显示/经纬网）、中（视口名）、右（分割/分离/全屏/关闭）
│  │  │    视口内浮层：指南针、坐标 HUD、比例尺、拾取标记
│  │  ├─ 中：视口区域 + 底部脚本面板（桌面可独立；Web 只能停靠）
│  │  └─ 右：360 px 属性栏（桌面可独立，Web 只能停靠；v1 无 AI 面板）
│  ├─ 底部：状态栏 + 状态/诊断面板（按视口归集，可折叠，默认 268 px）
│  ├─ 对话框：添加数据（显示目标视口）、飞往坐标、保存视点、设置、zip 入口选择、超限确认
│  ├─ 独立窗口：桌面端视口可分离为独立窗口；Web 不提供该入口
│  └─ 脚本：桌面/Web 底部面板；桌面可拖出为独立窗口，Web 只能停靠
└─ 移动 Shell（<1100 px，单视口版本）
   ├─ 精简顶部栏（图层 / 标题 / FPS / 飞往 / 更多）
   ├─ 单视口 + FAB + 底部导航（视图 / 图层 / 属性 / 更多）
   ├─ 图层抽屉、属性底部面板、状态底部面板
   ├─ 全屏页面：添加数据、设置
   └─ 底部 Sheet：飞往、视点、显示模式、图层操作
```

### 3.5 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 悬停、焦点 | 120 ms ease-out |
| 面板折叠、抽屉 | 220 ms `cubic-bezier(.2,.7,.2,1)` |
| 底部 Sheet | 280 ms 同曲线 |
| 提示 Toast | 入 160 ms / 停留 2.4 s / 出 200 ms |
| 相机飞行 | 由距离决定 600–1400 ms，`ease-in-out` |

尊重“减少动态效果”：关闭面板过渡、Toast 渐隐和相机缓动（直接到位）。

### 4.1 桌面基准（1440×900）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶部栏 56                                                                 │
├─────────────────────────────────────────────────────────────┬────────────┤
│ 视口区域（1–N）                                              │ 属性       │
│                                                             │ 320        │
│ 每视口标题栏：[树 4] [+]        视口 1        [分割/分离/…] │ 280–420    │
│ [显示模式浮层]                          [指南针]             │ 属性/配准/ │
│                                                             │ 拾取/统计  │
│ [坐标 HUD]                                    [比例尺/版权] │            │
├─────────────────────────────────────────────────────────────┴────────────┤
│ 状态/诊断面板 268（默认收起，展开时占满整行）                             │
├──────────────────────────────────────────────────────────────────────────┤
│ 状态栏 32                                                                 │
└──────────────────────────────────────────────────────────────────────────┘
```

- 桌面不再使用全局左侧图层面板；每个视口拥有自己的无背景图层树覆盖层，从标题栏最左侧按钮展开。
- 右栏用可拖分隔条，最小/最大宽度写入规范；双击分隔条恢复默认宽度。
- 视口不设最小尺寸；极小视口按容器查询收拢标题栏与浮层，仍可分割/关闭。
- 底部诊断面板默认收起；展开时高度 268（可拖 200–340），覆盖在工作区下方而不是浮在视口上。
- 全屏视口（`Ctrl+Shift+F`）隐藏右栏/脚本、诊断面板与状态栏，仅保留顶部栏、活动视口和视口浮层；`Esc` 退出。

### 4.2 紧凑桌面（1100–1359 px）

- 右栏 340；顶部栏只保留属性/脚本/设置图标；视口标题栏工具在 <420 px 缩到 20 px，<360 px 收进“⋯”。
- 品牌区只留图标；FPS 胶囊缩短为圆点 + 数字。
- 属性面板保持单对象布局，文字不换行；视口标题栏在窄宽度下收拢右侧操作。

### 4.3 断点

| 宽度 | 布局 |
| --- | --- |
| ≥1360 | 完整桌面 |
| 1100–1359 | 紧凑桌面 |
| <1100 | 移动 Shell（平板横屏也走移动逻辑） |
| ≤600 | 手机紧凑：顶部栏只留图标，底部导航文字 10 px |
| 横屏高度 <520 | 移动顶部栏 44，底部导航 52，Sheet 最高 88vh |

├─────────────────────────┤

- 底部面板：属性/状态/飞往/视点，圆角 16、拖拽手柄 42×4、最大高度 82vh；键盘弹出时面板内容整体上推，确认按钮始终可见。

- 所有主要按钮 ≥44×44，图标按钮 48×48 点击热区。

### 4.5 多视口布局（v1.0 重新基线）

桌面/Web 从单视口开始，通过分割形成递归布局；移动端保持单视口。

```
单视口                分割当前视口（左右）          继续分割视口 1（上下）
┌──────────┐        ┌────────┬────────┐          ┌────────┬────────┐
│ 视口 1   │        │ 视口 1 │ 视口 2 │          │ 视口 1a│ 视口 2 │
└──────────┘        └────────┴────────┘          ├────────┤        │
                                                   │ 视口 1b│        │
                                                   └────────┴────────┘
```

- **递归分割树**：每个叶子是一个视口；分割只把**目标视口**替换为一个新的分割节点，加入一个新视口；相邻视口的位置、尺寸和比例完全不变。
- **新视口为空**：新分割出的视口**没有任何数据**，也不创建 WGS84 椭球；需要时在视口内添加 WGS84 椭球（基础地球）或其他数据，或从其他视口拖入图层（共享引用）。
- **数量与尺寸**：不设可见视口数量上限，不设单视口最小尺寸；分割比例只受技术边界约束（0.02–0.98），允许出现很小的视口。
- **极小视口**：宽度或高度不足时标题栏进入紧凑模式：隐藏视口名与次要覆盖层，右侧操作收进“⋯”菜单，左侧图层树/添加仍保留；仍可分割、分离、最大化和关闭。
- **活动视口**：同一时间只有一个；点击视口、点击标题栏或 `Ctrl+1..9` 切换；更多视口用 `Ctrl+Tab` 循环；2 px accent 边框 + 居中视口名。
- **每视口图层树**：标题栏最左侧 `☰ 数量` 打开该视口图层树，`＋` 添加到该视口；不设全局左栏，树是无背景覆盖层，只有树按钮能收起，可多视口同时展开。
- **入口**：不提供会重排全部视口的 1/2/4 布局预设，也不在顶栏放“新建视口”。每个视口标题栏提供“左右分割 / 上下分割 / 分离窗口 / 最大化 / 关闭”。
- **独立设置**：每视口独立相机、图层栈、环境（渲染模式/背景/光照）和性能预算；相机属性属于相机对象，地形夸张属于 DEM，经纬网属于地球；这些设置只影响该视口。
- **全屏活动视口**：隐藏右栏/脚本、状态栏和其他视口，只保留活动视口与顶部栏；`Esc` 恢复原分屏树。
- **独立窗口（桌面）**：视口可分离为操作系统窗口，窗口内为精简视口工具栏；关闭窗口默认停靠回主窗口，显式“关闭视口”才销毁；独立窗口数量不设产品上限；Web 不支持独立窗口，移动端不提供分屏。
- **性能策略**：视口越多，非活动视口越主动降帧、降 LOD 和降渲染比例；全局预算不足时给出提示但不阻止继续分割；活动视口优先保证响应。

## 5. 组件规范

### 5.1 顶部工具栏

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 品牌 | 图标 + DigitalViewer + v1.0 + `▾` | 打开应用菜单：关于 / 设置 / 退出；不是窗口图标 |
| 右侧 | 属性、脚本、FPS、设置 | 属性/脚本按钮显示/隐藏对应面板；FPS 显示 60；相机模式不在顶栏，见每视口相机对象 |

- **顶栏不出现**“添加数据”“新建视口”“视口选择器”“飞往 / 视点 / 显示 / 经纬网”“全屏”：添加在每视口标题栏 `＋`，新建/全屏用每视口标题栏的分割/全屏按钮，飞往/视点/显示/经纬网在**视口标题栏左侧**（树/添加之后）。
- 顶栏命令（属性/脚本）作用于**活动视口**；切换活动视口后同步更新。相机模式属于该视口的相机对象，不在全局顶栏。
- **视口标题栏工具**：树/添加之后依次是 `[飞往] [视点 N] [显示] [经纬网]`；飞往=全局坐标对话框，视点/显示=锚定该视口的浮层，经纬网=该视口开关。窄视口只留图标，<360 px 收进该视口“⋯”菜单；视口名仍严格居中。

按钮规格：高 36，水平内边距 10，图标 16 + 文字 13，间距 6；主按钮使用 accent 底 + `--on-accent` 文字。悬停 `--surface-hover`；按下 `--surface-active`；开关类按钮按下态使用 `--accent-soft` 底 + accent 文字。

#### 5.1.1 窗口控制与品牌边界

**桌面端不在应用内绘制最小化、最大化、关闭按钮。** 窗口控制由操作系统提供：

- Windows/Linux：使用系统标题栏；最大/最小/关闭由窗口管理器处理。
- macOS：使用系统红黄绿按钮；绿灯是缩放/全屏，不等同于 Windows 最大化。
- Web：由浏览器标签页和窗口控制；移动端没有窗口概念。

应用内的品牌区承担的是**应用菜单**，不是窗口图标：

- 点击 `Logo + DigitalViewer + ▾` 打开菜单：关于、设置、退出。
- 关于：版本、引擎、包标识、语言、会话与隐私说明。
- 设置：语言、显示、坐标格式、性能与隐私。
- 退出：先显示退出步骤（取消任务 → 释放图层与 GPU → 清理临时文件），确认后执行 `DV-FUNC-PROJECT-007` 的退出流程。
- 原生窗口图标与标题单独设置（项目/导出预设、`DisplayServer`），不参与应用内交互。不要尝试把应用菜单“搬进”原生标题栏：Windows 只能设置窗口图标，macOS 不显示标题栏图标，Linux 取决于窗口管理器，Web/移动没有标题栏。
- 紧凑桌面（≤1359）隐藏字标，只保留 `Logo + ▾`，菜单仍可用；移动端没有该菜单，关于/退出入口放在“更多”面板。
- 顶部右侧的 `⛶` 是**全屏视口**，只隐藏面板，不改变操作系统窗口；不要命名为“最大化”。

### 5.2 每视口图层树

桌面不再使用全局左侧图层面板。每个视口标题栏最左侧提供图层树入口：

```text
[☰ 4] [＋]                 视口 1                  [左右] [上下] [分离] [⛶] [×]
```

- **树按钮**：`☰` + 图层数；有共享数据时加一个 4 px `info` 圆点；活动视口的树按钮使用 accent 色。点击展开；再次点击同一按钮收起。
- **添加按钮**：紧跟树按钮，始终添加到该视口；打开添加数据对话框并显示目标视口。
- **视口名居中**：标题栏只显示视口名；相机模式只放在该视口相机对象属性里，不放在标题栏或全局顶栏。
- **内联无背景树**：树是视口内的覆盖层，不是弹出面板；绝对定位在左上角（左 6 / 上 38），宽 `min(280px, 100% - 12px)`，最高 `calc(100% - 46px)`；**无背景、无边框、无阴影**，用文字阴影保证可读性。树随视口分割、拖动分隔条和缩放自动移动，始终贴在该视口左上角。
- **常驻语义**：只有点击该视口的树按钮才会收起；点击场景、切换活动视口、添加数据、分割视口都不会收起。多个视口可以同时展开各自的树。
- **输入命中**：节点行和可见滚动条接收树操作；树面板透明空白区域允许鼠标穿透到当前视口，旋转、平移和滚轮缩放正常生效。树行上的滚轮滚动树，不缩放场景。
- **无树头部行**：树内不出现“图层树 / 视口名 / 数量 / 添加”这一行；添加按钮只在视口标题栏的 `＋`。树从顶层分组直接开始，不设场景根节点。
- **树结构**：顶层是 `相机` 对象 + “底图 / 地形 / 三维数据 / 脚本”分组，分组下挂图层子节点；名称只负责选择，独立复选框切换图层显隐，chevron 展开或折叠；点击分组名称不切换折叠。折叠、选中项和滚动位置按视口保留，数据状态变化或动态增删节点不重置它们。相机模式、节点类型与运行状态放在属性面板，不附在树名称后面。
- **共享**：属性面板显示共享引用数；拖到另一视口建立引用。
- **极小视口**：树宽随视口收缩；视口本身不设最小尺寸；标题栏的视口名和树按钮按容器查询收拢。
- **视口标题栏工具**：树/添加之后提供飞往/视点/显示/经纬网；显示与视点浮层锚定该视口；窄视口只留图标，<360 px 收进该视口“⋯”菜单。
- **没有全局左栏**：跨视口概览由每个视口标题栏的树按钮（显示图层数）和共享徽标承担；顶部不再放视口选择器。

### 5.3 属性面板（按选中对象切换）

属性面板在右侧 360 px 栏；v1 没有 AI。属性可关闭、可拖出独立窗口；脚本在视口下方，也可关闭或拖出。视口默认没有数据，也不创建 WGS84 椭球；添加椭球数据后才显示地球和经纬网。

- **选中视口**：点击视口场景或标题栏 → 标题为 `视口 N`，副标题 `视口属性 · 布局与环境`，chip `独立`，右侧刷新按钮恢复视口默认。
- **选中相机**：点击图层树顶部的 `相机` 对象 → 标题 `相机`，副标题 `CAMERA · 模式 · 视口 N`，显示模式/投影/FOV/裁剪/当前视点；不显示视口布局、背景、数据源。
- **选中图层**：点击图层树行 → 标题为图层名，副标题为 `类型 · 状态 · 视口 N`，chip 为类型（3D TILES / OSGB / 影像 / DEM / 椭球 / 点云 / glTF）；不提供返回按钮，点视口或标题栏即可回到视口属性。
- **无混合**：选中视口时不显示相机/FOV/地形/经纬网/数据源；选中相机时不显示布局/背景/数据源；选中图层时不显示相机/布局/背景等无关字段。
- 头部 56：对象名（可截断）+ 类型/状态副标题 + 类型 chip；视口模式保留重置按钮，图层/相机不显示返回按钮。
- 内容内边距 14；区块间距 18；键值行 30（键 88 px，值右对齐/可截断）。

**按类型的字段**

| 对象 | 自身/数据属性 | 视口/显示属性 |
| --- | --- | --- |
| 视口 | 名称、布局位置、尺寸、窗口、活动状态、环境（渲染模式/背景/光照）、性能（帧率/渲染比例/MSAA） | — |
| 相机 | 模式、投影、FOV、近/远裁剪、当前经度/纬度/高度/旋转/视距 | — |
| 3D Tiles | 格式、瓦片数、几何误差、屏幕空间误差、内存 | 可见、透明度、显示轮廓 |
| OSGB | 格式、LOD 层数、最大屏幕误差、纹理压缩、根节点 | 可见、透明度、线框 |
| 影像 | 格式、坐标参考、层级范围、瓦片数、版权 | 可见、透明度、亮度、对比度 |
| DEM | 格式、分辨率、高程范围、NoData、坐标参考 | 可见、透明度、参与地形、地形夸张 |
| 椭球数据 | WGS84、长半轴、扁率、基准 | 经纬网 |
| 点云 | 格式、点数、点间距、颜色、预算 | 可见、透明度、点大小、颜色模式 |
| glTF | 格式、网格数、材质数、动画数、包围盒 | 可见、透明度、线框 |

- **共享数据**：同一数据被多个视口引用时，数据区标题为“共享数据”，并提示“数据源属性影响 N 个视口；本视口显示属性只影响当前视口”。
- **状态区**：状态/加载进度/共享引用；3D 数据可再加请求、Resident、失败数。
- **操作**：重新加载、暂停/恢复、从当前视口移除；地球不提供移除。
- 图层内部的“属性 / 配准 / 拾取 / 统计”只作为该图层的高级二级标签，不跨到视口；具体字段仍按类型收敛，不把无关类型字段混入。

### 5.4 视口浮层

- 左上：不放假控件；飞往/视点/显示/经纬网已在视口标题栏，避免和图层树/场景争空间。
- 右上：指南针 44 px（N 红标）；下方垂直缩放 +/−。
- 左下：坐标 HUD——`经度 纬度 · 高度`，第二行 `航向 / 俯仰 / 视距`；等宽数字；点击复制。
- 右下：比例尺 + 影像 Attribution + 当前层级；Attribution 在图层关闭后移除。
- 拾取标记：accent 水滴 + 脉冲环；伴随 220 px 紧凑卡片（Batch、高度、飞往/关闭）。
- 飞行状态：顶部中央胶囊“飞往 121.4737°E, 31.2304°N”+ 取消按钮；飞行结束自动消失。
- 加载态：视口中央不遮挡的 32 px 环形进度 + “正在加载瓦片 68%”；超过 1.5 s 才显示，避免闪烁。

### 5.5 状态栏与诊断面板

状态栏 32：`● 就绪`｜`请求 6`｜`网络 8.4 MB/s`｜`Resident 622 MB / 1 GB`（含 3 px 预算条）｜右侧 `CPU 5.8 ms`、`2 条警告`、`状态 ▴`。

诊断面板：
- 头部 40：标题 + 标签“概览 / 错误 2”+ 右侧“复制”“导出脱敏报告”“清空”。
- 概览表格：列 `图层 | 阶段 | 请求 | 等待 | Resident | 可见 | 失败`；行高 32；阶段用状态胶囊。
- 错误列表：每条包含时间、图层、阶段、脱敏 URI、错误码、建议、复制按钮；错误码如 `HTTP 403`、`CORS`、`ZIP_ESCAPE`、`TILES_EXT_REQUIRED`。
- 底部说明：“报告自动移除 Token、Authorization、Cookie 与敏感查询参数。”
- 暂停/恢复、重载按钮直接出现在错误行，减少跳转。

### 5.6 对话框

统一规格：遮罩 `--scrim`，卡片最大宽 720（添加数据）/ 420（飞往、设置），圆角 10，头部 56，内容内边距 16–20，底部操作区 60 右对齐；`Esc` 关闭，主按钮默认焦点。

**添加数据**（720×600）：
1. 来源：本地文件、本地目录、ZIP 数据包、远程地址、WMTS 影像、Cesium ion、**GDScript 脚本**。
2. 右侧表单按来源切换；顶部 32 px 标题 + 格式徽标。GDScript 选择 `.gd` 后校验 `extends Node` 与 `run(viewer)`，创建“脚本”图层并打开脚本面板。
3. 底部：取消 / 添加。添加后立即创建图层并进入加载态，不阻塞对话框关闭。
4. 校验失败在字段下方就地显示，不弹二次错误框。
5. ZIP 多入口：解析后出现“选择入口文件”列表（格式、路径、大小），默认选中唯一可识别项。
6. 远程文件超限：显示大小、平台上限、内存风险与“仅本次会话继续”确认。

**飞往坐标**（420）：经度、纬度、观察高度、航向、俯仰；输入支持十进制度与 DMS；错误就地提示；底部“取消 / 开始飞行”。飞行中同一入口变为“取消飞行”。

**设置**（480）：语言（跟随系统/中文/English）、坐标格式（十进制/DMS）、显示（经纬网默认、显示模式）、性能摘要（只读预算）、隐私说明；v1 只持久化语言与非敏感显示偏好。

### 5.7 右侧属性与脚本面板

v1 **不内置 AI 助手**：没有 AI 面板、Composer、模型管理或 AI 设置。

- **顶栏入口**：`属性 / 脚本` 两个按钮，点击打开/关闭；面板独立成窗口时按钮显示蓝点。没有常驻最右按钮列。
- **布局**：右栏 360 只承载属性；脚本在视口下方；中间是视口。
- **关闭**：每个面板头部都有 `×`。属性关闭后右栏消失，用顶栏 `属性` 重开；脚本关闭后底栏消失，用顶栏 `脚本` 重开。
- **独立窗口（仅桌面）**：每个面板头部有“独立窗口”按钮。面板拖出后成为浮动窗口，原停靠位释放；可拖标题栏移动、拖右下角缩放；头部按钮变为“停靠”，可回到原位置。Web 隐藏该按钮，面板只能停靠。
- **尺寸**：右栏 300–520；脚本 220–520；独立窗口 320–900 × 260–760。
- **选择**：点相机/图层只更新右侧属性，不关闭脚本；点视口只更新活动视口。脚本保持应用级状态。
- **外部 AI**：Codex / Harness / CLI 通过本机 MCP 使用运行时脚本 API；它只是外部客户端，不获得额外能力，不读仓库、不修改产品、不跑测试，详见 5.11。
- 原 AI 面板/Composer 设计不进入 v1；如后续恢复，必须重新评审。

### 5.8 底部脚本面板与独立脚本窗口

- 脚本默认停靠在**视口下方**，横跨主视口区；默认高 300，拖顶部边缘 220–520。
- **关闭 / 独立（独立仅桌面）**：工具栏提供 `×`、独立窗口；Web 只提供关闭。关闭面板或浮窗保留脚本执行、草稿和输出；关闭后底栏消失；桌面独立后底部释放、脚本变成浮动窗口。
- 工具栏 36：GDScript 标识、文件名、`应用级`、新建/打开/保存、保存状态、运行、停止、独立、关闭。
- 编辑器：可手工编辑的 CodeEdit/代码区，行号、GDScript 语法高亮、查找、`Ctrl+S` 保存、`Ctrl+Enter` 运行；新建/打开/保存保留，不把编辑能力降级为只读。
- 编辑器和输出左右并排（输出 320）；错误可定位到源码行。
- 外部 AI 生成的 GDScript 草案通过“查看脚本/审查并运行”放入该面板；不自动运行，必须由用户确认信任后手动点运行。
- 脚本是应用级会话：切换活动视口不停止、不重置、不重新绑定；需要操作视口时由脚本显式获取。
- 每份文档首次运行或代码变化后显示信任确认；本次应用会话中已确认且代码未变可直接重跑，停止和重开面板不清除确认。风险条常驻：脚本拥有应用权限，同步死循环无法通过停止按钮中断。
- 独立脚本窗口与底部脚本共用同一编辑内容；停靠/独立不重置代码或输出。

- 底部导航：视图（关闭所有面板）、图层（抽屉）、属性（底部面板）、更多（状态/添加/显示）。

### 5.10 多视口与独立窗口

**视口标题栏**（每个叶子视口 32 px，浮在视口顶部，三区布局）：

```
[☰ 4] [＋] [✈] [🔖 2] [☷] [▦]        视口 1        [⊞] [⊟] [⧉] [⛶] [×]
 ↑ 左：树 + 添加 + 飞往/视点/显示/经纬网             ↑ 中：视口名          ↑ 右：视口操作
```

- 活动视口标题栏 accent 文字 + 2 px 边框；非活动视口降为 55% 对比度；不再使用圆点。
- 视口名绝对居中；左右按钮不参与居中计算；标题最大宽度预留按钮空间并省略。
- 宽度 <520 px 时标题收窄；<420 px 时工具按钮缩到 20 px；<360 px 时飞往/视点/显示/经纬网收进该视口“⋯”菜单，树/添加仍保留；<240 px 时隐藏视口浮层与 Attribution；<150 px 时隐藏视口名。不设最小尺寸。
- 分割只作用于当前视口：原视口成为新分割节点的一个子节点，新视口为空（无数据，需添加 WGS84 椭球），相邻视口不受影响；关闭视口时只合并该节点空间，最后一个视口不允许关闭（只能重置）。
- `Ctrl+1..9` 激活对应视口，`Ctrl+Tab` 循环；点击视口内任意区域也会激活；键盘输入只路由到活动视口。
- 不在顶栏放“新建视口”；新建视口只能通过视口标题栏的分割按钮；不提供会重排其他视口的全局 1/2/4 布局预设。

**图层树入口**

- 标题栏最左侧的 `☰ N` 打开当前视口的图层树；`＋` 添加到当前视口。
- 图层树是无背景内联覆盖层，只有树按钮能收起；详情见 5.2。


**图层树**

- 每个视口只显示自己的图层树；不提供全局左侧图层面板。
- 树从顶层分组“底图 / 地形 / 三维数据”开始，向下挂图层子节点；不显示树头部行，也不显示场景根节点。树底部显示“拖到其他视口共享 · 会话不保存”。
- 图层行新增拖拽柄与共享徽标：`🔗 共享 · 2`；副标题或 tooltip 标明来源视口。
- 拖拽规则：在树内拖动 = 排序；拖到另一个视口 = 建立共享引用；拖到空白 = 取消。
- 共享图层移除时只解除当前视口引用；最后引用移除才释放数据；重载共享数据需确认“影响 N 个视口”。
- 每个视口标题栏的树按钮显示该视口图层数；顶部不设视口选择器，活动视口通过点击视口/标题栏或 `Ctrl+1..9` 切换。全局数据/共享概览作为诊断面板的后续增强。

**属性面板**

- 头部显示当前对象：`视口 1` + `视口属性 · 布局与环境`、`相机` + `CAMERA · 模式 · 视口 1`，或 `图层名` + `类型 · 状态 · 视口 1`；chip 为 `独立`、`CAMERA` 或图层类型；视口模式保留重置按钮，相机/图层模式不显示返回按钮。
- 选中对象互斥：点视口/标题栏 → 视口属性；点树顶部 `相机` → 相机属性；点图层树行 → 该图层属性；不把布局/相机/数据源字段混排。
- 视口属性只包含：名称、布局位置、尺寸、窗口、活动状态、环境（渲染模式/背景/光照）、性能（帧率/渲染比例/MSAA）。
- 相机属性包含：模式、投影、FOV、近/远裁剪、当前经度/纬度/高度/旋转/视距。
- 属性面板在右侧栏；脚本在视口底部；两者都可关闭、可拖出为独立窗口（桌面）、可停靠回来。v1 没有 AI 面板。
- 属性始终显示单对象（视口/相机/图层）；点树中相机/图层只更新属性，不关闭脚本；点视口只更新目标视口。
- 图层属性按类型收敛：3D Tiles / OSGB / 影像 / DEM / 椭球 / 点云 / glTF 各自字段见 5.3；DEM 拥有参与地形/地形夸张，椭球拥有经纬网；数据区与“本视口显示”分区，共享数据提示影响 N 个视口。
- 切换活动视口时显示该视口自己的选中对象：相机、图层或视口；不沿用上一个视口的选择。

**添加数据**

- 对话框标题旁显示目标：`添加到：视口 2`。
- 添加流程始终创建独立数据与图层，不自动复制到其他视口；关闭对话框后其他视口统计不变。
- 需要共享时，添加完成后从图层树拖到目标视口；或在图层菜单选择“共享到视口…”。

**独立窗口（桌面）**

- 视口标题栏“分离”把该视口移到独立操作系统窗口；主窗口保留占位卡片“视口 2 已在独立窗口 · 停靠 / 聚焦”。
- 独立窗口是视口级窗口，不是完整第二套主界面：44 px 工具栏 + 视口 + 每视口图层树/设置；包含 `＋ 添加数据`、图层、设置、停靠回主窗口、关闭。
- 关闭独立窗口默认停靠回主窗口原位置；显式“关闭视口”才销毁并二次确认。
- 独立窗口与主窗口共享同一全局预算、数据缓存和引用计数；窗口数量不设产品上限；Web 不支持，移动端不提供。

**脚本**

- 脚本是**应用级**面板，不显示 `目标 视口`；桌面可独立成窗口，Web 只能停靠。
- v1 没有 AI 面板；外部 AI 通过 MCP 提交脚本草案，草案进入脚本面板后必须由用户审查、确认信任并手动运行。
- 同一时间只允许一个脚本运行会话；脚本可显式引用某个视口，但面板本身不绑定。
- 切换活动视口、关闭面板或浮窗不停止脚本、不重置输出；停止按钮或移除脚本结束对应会话，重置场景结束全部会话。
- 脚本 `run(viewer)` 的 viewer 是应用上下文；脚本显式访问视口；停止或移除脚本清理对应会话。脚本面板不提供展开按钮，需要更大编辑区时拖出为独立窗口。

**诊断与性能**

- 诊断表新增“视口”列；共享数据行显示引用数；全局 Resident 为所有视口合计。
- 活动视口全帧；非活动视口按数量自适应降帧、降 LOD 和降渲染比例，不设数量上限。
- 共享数据只下载/解析一次；独立数据按视口分别计数；超预算先降非活动视口质量，并提示但不阻止继续分割。
- 状态栏显示 `视口 2 · 活动`、当前视口总数、全局请求/Resident 和“自适应降级”提示。

### 5.11 自动化 API / 外部 AI

- **API 优先**：v1 不内置 AI；DigitalViewer 暴露脚本 API 和本机 MCP / Plugin Bridge，Codex、Harness、CLI、CI 通过同一套 API 控制运行时场景。
- **传输设置**：设置 → 自动化 / 外部 AI 可在 MCP 与 Plugin Bridge 之间切换（互斥）；显示 `127.0.0.1:8731/mcp` 或 `127.0.0.1:8731/bridge`、权限（只读场景 / 运行脚本 / 截图）和“v1 不内置 AI”说明；可复制端点与令牌。
- **工具范围**：`scene.describe`、`viewport.list`、`script.inspect`、`script.propose`、`script.run`、`capture.screenshot`、`audit.list`；不提供 shell、文件系统、网络或 JSON 场景写接口。
- **产品不可修改**：DigitalViewer 发布后是不可变运行时；AI 不能修改源码、二进制、插件、安装包、依赖或构建配置，也不能安装插件或注入原生代码。GDScript 只是运行时脚本，不写回安装目录。
- **权限与审计**：本机端点默认只监听 loopback；持久 Bearer 令牌，设置中可导入/重置，重启保持不变；每次调用记录客户端、脚本版本、检查点、结果；可在设置关闭。
- **Web / 移动**：Web 不暴露本机 MCP/Plugin；移动端无脚本、无 AI；桌面本地桥接是唯一 AI 入口。
- 详细边界：[自动化 API / MCP](../../docs/automation-api.md)、[Plugin Bridge](../../docs/plugin-bridge.md)。

## 6. 关键流程

### 6.1 添加远程 3D Tiles

1. `添加数据 → 远程地址`。
2. 输入 URL（支持 `tileset.json`、`.b3dm`、`.glb`、`.zip`）。
3. 就地校验协议与扩展名；HTTP 资源提示 “Web 部署需 HTTPS/CORS”。
4. `添加` → 图层立即出现（阶段=排队），对话框关闭。
5. 面板状态依次为 下载 → 解析 → 打包 → 上传 → 就绪；失败则红色行 + 错误面板条目。
6. `聚焦` 按钮在就绪后可用。

### 6.2 添加影像 / DEM

- 影像：类型（XYZ / WMTS URL / WMTS Capabilities / ion）→ CRS（3857 / 4326）→ TMS 开关 → 层级范围 → Attribution → 名称。
- WMTS Capabilities：选择 Layer / Style / Format / TileMatrixSet；不支持的 CRS 直接禁用并给出原因；不提供 Dimension。
- DEM：预切片清单 / GeoTIFF / COG / 目录；多 DEM 按列表从上到下覆盖，上层 NoData 回退下层；每层可设 scale/offset/垂直偏移/NoData/层级/边界；全局夸张独立于图层顺序。

### 6.3 拾取

视图单击/长按 → 取最近命中 → 右侧自动切到“拾取”并高亮标记 → 显示完整属性；隐藏/删除图层后清除结果。移动端用底部面板展示同一内容。

### 6.4 飞往与视点

视口标题栏“飞往”或移动端坐标 HUD → 输入经纬高与可选姿态 → 平滑飞行（可取消）；“视点”浮层保存当前视点（自动命名“视点 1”），支持飞往/重命名/删除；退出应用即清空，不写盘。

### 6.5 诊断导出

错误行“复制”复制单条脱敏信息；“导出脱敏报告”生成文本/Markdown，包含环境、图层、状态、错误与预算，绝不包含 Token、Authorization、Cookie 或完整敏感查询值。

### 6.6 分割视口与活动视口

1. 应用从单视口启动；点击视口标题栏“左右分割/上下分割”分割当前视口；顶栏不提供“新建视口”。
2. **只分割目标视口**：该视口被替换为一个分割节点，相邻视口的位置、尺寸和比例不变；不设分割次数上限。
3. 新视口默认是**空视口**（无数据、无 WGS84 椭球），拥有独立相机和默认显示设置；不会自动复制活动视口的数据。
4. 需要对比时，从活动视口图层树把图层拖到新视口，建立共享引用；或在新视口内添加 WGS84 椭球/其他数据创建独立数据。
5. 点击视口、标题栏或 `Ctrl+1..9`（`Ctrl+Tab` 循环）切换活动视口；图层树、右侧属性、添加数据随活动视口切换；脚本保持应用级，不重置。
6. 关闭视口时只合并该节点空间，相邻子树不变；含图层或运行中的脚本时先确认；最后一个视口只能重置，不能关闭。
7. 全屏只最大化活动视口；退出后恢复原分屏树与比例。

### 6.7 数据共享（拖放）

1. 从活动视口图层树按住图层行拖出，拖到目标视口；目标视口出现 accent 描边和“共享到此视口”提示。
2. 松开后创建共享引用：数据只下载/解析一次，两个视口的显隐、透明度、顺序、渲染模式各自独立；图层行出现 `共享 · N`。
3. 在列表内拖动仍是排序；拖到空白取消；拖到已有同一共享数据的视口不重复创建。
4. 移除一个共享引用只解除该视口；最后一个引用移除时取消任务并释放 CPU/GPU。重载共享数据前提示“影响 N 个视口”。
5. 添加数据流程不产生共享；若需要共享，先添加再拖放。

### 6.8 独立窗口（桌面）

1. 视口标题栏“分离”把该视口移动到独立操作系统窗口；主窗口保留占位卡片（停靠/聚焦）。
2. 独立窗口使用精简工具栏：`视口 2`、添加数据、图层、设置、停靠、关闭；数据、相机和设置与分离前一致。
3. 关闭窗口默认停靠回主窗口原分屏位置；显式“关闭视口”才销毁并确认；Web 与移动端不提供该入口。

## 7. 状态与错误

| 状态 | 色彩 | 图层行 | 状态栏 / 诊断 |
| --- | --- | --- | --- |
| 未加载 | 灰 | 空心点 | “未加载” |
| 排队 | 蓝 | 环形进度 0% | 请求计数 +1 |
| 下载 | 蓝 | 环形进度 + 百分比 | 网络吞吐 |
| 解析/打包/上传 | 蓝 | 百分比 | 阶段胶囊 |
| 就绪 | 绿 | 实心点 | “就绪” |
| 暂停 | 琥珀 | 暂停图标 | “已暂停” |
| 部分失败 | 琥珀 | 三角 | “部分失败 · N 项” |
| 失败 | 红 | 红点 | 错误面板条目 + 重试 |
| 取消 | 灰 | 空心点 | “已取消” |
| 共享 | 蓝 | `🔗 共享 · N` 徽标 | 共享引用 N |
| 活动视口 | accent | 2 px 边框 + 编号 | 状态栏“活动” |
| 非活动视口 | 灰 | 标题栏 55% 对比 | 降帧 / 按需更新 |
| 独立窗口 | 蓝 | 窗口图标 | 主窗口占位卡片 |
| 空视口 | 灰 | “空视口 · 添加数据” | 0 图层 |
| 极小视口 | 灰 | 仅编号 + “⋯” | 紧凑模式，不限制尺寸 |

**错误文案结构**：`视口 2 · 图层名 · 阶段` → `错误码` → `一句可读原因` → `一条建议` → `复制`。示例：

> 视口 2 · 城市建筑 3D Tiles · 下载
> `HTTP 403` 服务器拒绝访问 tileset.json。
> 检查 Token 是否过期，或该资源是否允许当前来源访问。
> [复制]　[更新 Token]　[重试]

CORS、TLS、ZIP 路径穿越、超限、未知 required extension 分别使用专用错误码与建议，不复用“加载失败”。

- 中文为设计源语言，英文同步维护；英文文案比中文长 30–50%，所有按钮最小宽度按英文预留。

| 数据共享 | 新增 `DataSet` 引用计数；每个视口持有独立 `LayerInstance` |

| 自动化 | `scripts/automation/mcp_server.gd`（本机 MCP；仅运行时场景权限） |
| 状态模型 | `scripts/app_state.gd` 拆为 `ViewportStore` / `LayerStore` / `DataStore` / `DiagnosticsStore` |

**Godot 实现约定**：

- 面板用 `PanelContainer` + `StyleBoxFlat`，避免每处手写颜色；颜色/字号/间距全部来自 Theme 与常量表。
- 右栏用 `HSplitContainer`，最小宽度由 `custom_minimum_size` 控制；关闭用 `visible`，不重建节点；独立窗口用 `Window` 或浮动层，停靠时重父回右栏/底部槽。
- 每视口图层树是视口内的内联覆盖层（`Control` 绝对定位左上），不是 `PopupPanel`；不占用视口布局宽度；树内列表复用轻量自定义行。
- 图层树用轻量自定义行（沿用 `layer_item.tscn`），不要用 `Tree` 以保留拖拽与多状态布局；列表更新按 diff 刷新，避免每次重建。
- 对话框用 `Window` 或全屏 `Control` + 遮罩；移动 Sheet 用 `PanelContainer` + `Tween` 位移。
- 诊断数值 4 Hz 节流；错误/状态变化走信号，禁止每帧轮询。
- 所有用户文案 `tr()`；翻译表 `i18n/` 下 CSV，启动读取 `OS.get_locale()`。
- 移动安全区通过 `DisplayServer.get_display_safe_area()` 计算；键盘用 `DisplayServer.virtual_keyboard_show()` 与 `size_changed` 适配。
- 图标使用内嵌 SVG 或项目 `assets/icons/`，统一 16/18/24 三档，不混用 emoji。
- **视口树**：`ViewportTree` 保存分割方向、比例和动态叶子视口；分割只替换目标叶子，相邻子树不变；不设叶子数量上限和最小尺寸。每个叶子 `ViewportSession` 持有自己的 `SubViewport`、`World3D`、相机、图层栈和设置；移动/布局切换只改显示，不复制状态。
- **活动视口**：全局唯一 `active_viewport_id`；图层树、右侧属性、添加数据订阅它；输入事件先路由到活动视口；脚本保持应用级；`Ctrl+1..9` 与 `Ctrl+Tab` 支持切换。
- **数据共享**：`DataSet` 负责下载、解析、缓存和 GPU 资源；`LayerInstance` 属于单个视口，保存显隐/透明度/顺序/渲染模式。拖放只增加 `DataSet` 引用，移除减少引用，归零时释放。
- **独立窗口**：桌面端用 `Window` 承载目标 `SubViewport`；主窗口显示占位卡片；停靠时把 `SubViewport` 重父回主树；Web/移动端不创建额外窗口。
- **性能**：全局预算器统一分配；活动视口全帧，非活动视口按数量自适应降帧/LOD/渲染比例；不设产品上限，超预算提示并降级但不阻止分割；共享数据只计一次内存。
- **脚本**：应用级，不绑定活动视口；多个文档可同时运行；切换视口、关闭面板或浮窗不停止脚本，停止/移除只影响对应脚本，重置结束全部会话。
- **测试**：覆盖 2/4/6+ 视口、分割隔离、共享/独立数据、拖放引用计数、独立窗口停靠、输入路由、布局切换状态保持与资源释放。

## 13. 待确认（影响实现，不阻塞原型评审）

1. **主题范围**：v1 是否只发布深色？浅色仅作设计验证，建议 v1 砍掉浅色以减少六端口径。
2. **右侧栏位**：v1 右栏只放属性；不再为 AI 预留列。
3. **底部诊断**：全宽抽屉（推荐，符合“底部状态/错误面板”）还是仅视口下方？
4. **视口标题栏密度**：<420 px 时工具缩到 20 px、<360 px 收入“⋯”是否可接受？
5. **DEM/影像排序**：拖拽 + 菜单上移/下移（推荐），还是只保留菜单？
6. **移动“更多”层级**：已确认移动端不做脚本和 AI，保持四项导航；更多只放状态、设置、关于。
7. **共享数据呈现**：默认共享底层数据、各视口显隐/透明度/顺序/渲染模式独立；是否要求这些设置也同步？
8. **独立窗口关闭**：默认关闭窗口停靠回主窗口，显式“关闭视口”才销毁；是否改为关闭即销毁？
9. **共享数据重载**：默认影响全部引用并确认；是否允许只重载单个引用？

> 已确认、不再列为待确认：不设视口数量上限、不设单视口最小尺寸、分割只影响目标视口、移动端单视口、v1 不内置 AI、脚本为应用级不绑定视口。
