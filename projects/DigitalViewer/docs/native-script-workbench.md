# DigitalViewer 桌面原生脚本工作台

脚本面板默认停靠在视口下方，可以关闭、重新打开，桌面还可分离为独立窗口。多个脚本可以同时运行，每个脚本拥有独立的实例、草稿、输出和运行快照。关闭面板或其独立窗口只收起界面，脚本继续运行；切换脚本、视口、分屏、分离、停靠同样不会停止脚本。执行器由应用节点持有，不随面板重新挂载而退出。帮助、信任提示和运行状态支持中英文。

## 使用

在视口的“添加数据”中选择“GDScript 脚本”：数据源留空会新建脚本，也可浏览并选择 `.gd` 文件。添加后立即创建脚本图层并打开对应文档；导入只进行文本入口检查，不编译或执行。点击顶栏“脚本”也可新建脚本、打开保存文件或加载示例。

工作台顶部下拉框切换文档；即使文件名相同，也会使用不同的脚本 ID 区分。新建、导入、示例和 MCP 草案均新增文档，保留其它文档的未保存修改。每份文档首次点击“运行”时，审查提示并勾选信任确认；编译和静态初始化都位于确认之后。同一次应用会话内，代码与该文档最近一次确认的版本一致时，重跑直接执行，不再弹窗；停止、重置、关闭或重开面板不清除确认。代码修改后须重新确认，等待或取消确认不影响旧版本继续运行。确认绑定点击运行时的文档和源码，后续切换文档或编辑不会改变这次确认的对象。确认记录不保存到磁盘；移除后重新导入、同名新文档或重启应用都须重新确认。保存位置为 `user://scripts`，仅接受单个 `.gd` 文件名，覆盖已有文件需要确认；没有自动保存或自动恢复执行。

视口图层树的“脚本”组显示脚本名称、运行实例与生成节点。点击名称只选中，独立复选框控制图层显隐，箭头控制折叠；刷新保留折叠、选中项和滚动位置。树高度跟随视口可用高度。类型、状态和共享引用数放在属性面板，点击生成节点可查看该节点的实际类型、路径及变换；停止后已删除节点的选择回退到所属脚本图层。图层属性面板可打开、运行、停止或移除所选脚本。工作台“场景”页同时列出应用级脚本实例和各视口内容，节点类型及脚本状态显示在下方属性区。脚本显式访问其它视口的 `content(id)` 时会在那里建立同一脚本的图层引用，显隐和透明度分别生效。

```gdscript
extends Node
func run(viewer) -> void:
    var view = viewer.viewport("view_1")
    if view == null:
        return
    var container = viewer.content("view_1")
    var node = MeshInstance3D.new()
    node.mesh = BoxMesh.new()
    container.add_child(node)
    view.frame_bounds(AABB(Vector3(-1, -1, -1), Vector3(2, 2, 2)))
```

| API | 返回 |
| --- | --- |
| `viewer.viewport_ids()` | 当前视口 ID 数组 |
| `viewer.viewport(id)` | 指定视口场景；不存在则为 null |
| `viewer.content(id)` | 该视口内属于本次脚本的 Node3D 容器；同一会话重复调用返回同一容器，不存在的视口返回 null |
| `view.root / camera / environment` | 实际 Godot 对象 |
| `view.object("globe")` | 已添加的椭球，未添加则为 null |
| `view.pose()` / `restore_pose(pose)` | 相机导航状态 |

这些真实对象引用不是安全白名单。脚本可以使用原生类、材质、Shader、信号和 `_process`。活动视口改变不会重定向已有引用。

`viewport_ids()` 返回视口列表，不是脚本列表。多个脚本可以同时使用 `ids[0]`；只有至少两个视口时才能访问 `ids[1]`。已有脚本图层不代表执行成功：入口异常会将图层标记为失败，错误行号在“输出”页。保存文件被外部修改后，需重新打开文件，已有文档不会覆盖未保存草稿。

## 生命周期与边界

- 入口必须继承 Node 或其子类，提供非静态 `run(viewer)`，构造函数不能要求必填参数。源码上限为 64 KiB。
- 停止或重新运行仅清理所选脚本的实例及 `viewer.content(id)` 容器，保留其它脚本和对其它对象的直接修改。错误只结束出错的会话。
- 关闭停靠面板、浮窗系统关闭按钮或浮窗内的“关闭”按钮均保留执行、草稿和输出；有待确认操作时取消该操作。重开面板不会重启脚本。
- 移除脚本会停止它并删除所有视口中的该脚本引用；未保存修改须确认丢弃。关闭单个视口只释放该视口引用，最后一个引用释放时清理脚本。
- 重置停止所有脚本，重新实例化现存图层并恢复已有视口的导航、环境和部分图层状态；不是任意场景事务回滚。脚本删除的任意对象、被原地修改的共享资源、文件/网络/进程副作用不保证恢复。
- 脚本在主线程执行，不是沙箱；同步死循环会阻塞 UI，停止按钮无法抢占。只运行自己信任的代码。
- 输出有界，提供编译/运行错误、行号和可用调用栈；编辑后点击旧错误会显示运行快照。
- 场景树为真实节点的只读检查。补全为常用词提示；原生断点、单步、暂停局部变量和 VM 看门狗未实现。

MCP 草案经过同一面板和信任门；没有 JSON 场景写通道。`script.run` 权限只允许请求用户运行，不代替用户确认。调试和测试以 `tools/Test-Desktop.ps1` 为准；旧 `tests/scripting_smoke.tscn` 对应旧单视口原型，已不作为桌面入口回归。
